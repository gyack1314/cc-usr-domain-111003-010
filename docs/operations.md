# 运行与资料管理

开发环境需要 Python 3.11以上；容器采用 Python 3.12及 Chromium。固定 Playwright 版本与系统浏览器配套，不使用真实企业账号。默认仅监听127.0.0.1，容器映射时显式绑定到0.0.0.0。生产门户、外部身份和访问控制不在这个本地服务中。

portal_data 是合成门户的只读服务数据，materials 是可直接使用的本地业务材料。state/portal 保存草稿及修订历史，删除状态目录会清空草稿，应先备份。每个实例的 --state 必须不同，避免互相写入。源资料更改后重启服务，内容摘要随文件改变；既有草稿保留旧引用，保存修订时重新校验，旧结论不自动获得新证据。

内部私有说明与对外副本应放不同目录，材料工具不会替使用者裁决权限或主动脱敏。公开文书不应包含个人映射、内部争议或其他接收方资料。草稿不构成任何审批。所有业务日期以 materials/policy.md 为准，系统当前日期不参与效力判断。

浏览器检查在临时目录启动服务并产生独立样例草稿，退出后清理临时状态，不占用日常门户的草稿编号。测试校验的是已有接口与计算原语，不包含具体业务方案。
